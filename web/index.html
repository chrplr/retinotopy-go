Retinotopic mapping

Fixate the centre dot and press any key the moment it changes colour.

Large download. This experiment embeds 1 780 stimulus images, so the page has to fetch about 135 MB before it can start. Use a wired or fast connection, and expect the first load to take a while. Your browser will cache it afterwards.

Not for scanner or timing-critical use. Browser frame timing is not the desktop build's. Use the native binary for any session whose onsets matter.

Screen width and viewing distance set the stimulus scale (15° maximum eccentricity). Measure them — the defaults are a placeholder, and a run recorded at the wrong visual angle looks perfectly normal afterwards.
